# Pulkit Pareek

I like building open-source apps that solve a real pain point — then shipping them end-to-end so they actually run, not just demo well.

A few of those below, from 90 public repositories.

## Selected Work

**[AirLocal](https://github.com/pulkitpareek18/AirLocal)** — Cross-platform file transfer with no app install. Browser-to-browser P2P transfer over WebRTC data channels, QR-code / room-code pairing, and a Cloudflare Worker that handles discovery and signaling (file contents never touch the server). React 18, TypeScript, Vite, WebRTC, Cloudflare Workers. Live at [airlocal.online](https://airlocal.online).

**[ZeroAuth](https://github.com/zeroauth-dev/ZeroAuth)** — Enterprise authentication designed so a breach exposes nothing. Zero-knowledge biometric verification (Groth16 proofs computed on-device), SAML 2.0, OAuth 2.0 / OIDC, with decentralized identity anchored on Base L2. Built on the `pramaan` ZK-biometric protocol — Indian Patent IN202311041001 (granted). TypeScript, Node.js, Circom, Solidity, Kotlin. Live at [zeroauth.dev](https://zeroauth.dev).

**[CadenceRelay](https://github.com/pulkitpareek18/CadenceRelay)** — Self-hosted bulk email platform. Sends 100K+ personalized emails via Gmail SMTP or AWS SES, with throttling, open/click tracking, and deliverability analytics. React 18, TypeScript, Node.js/Express, BullMQ, Nodemailer, PostgreSQL 16, Redis 7, Docker.

**[AERIS](https://github.com/pulkitpareek18/AERIS)** — Passive presence detection from Wi-Fi channel state information (CSI). Nexmon CSI capture on a Raspberry Pi streams signal data to an edge-ML pipeline, detecting presence with no cameras or extra sensors. Python, FastAPI, PyTorch, Next.js, Raspberry Pi (Nexmon).

**[gcc-riscv](https://github.com/pulkitpareek18/gcc-riscv)** — A working GCC cross-compiler toolchain targeting RISC-V, alongside a research write-up on instruction-set architectures and the RISC-V compilation flow. C, C++, GNU toolchain, RISC-V.
